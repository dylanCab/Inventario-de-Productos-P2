# Inventario-de-Productos-P2
Descripción
Este programa en C permite gestionar un inventario pequeño (hasta 10 productos) mediante arreglos paralelos para nombres y precios. El sistema facilita operaciones frecuentes de tienda: registrar productos, calcular el precio total del inventario, identificar el producto más caro y el más barato, calcular el precio promedio, buscar un producto por nombre y listar todos los productos. El diseño es modular: la lógica está separada en funciones y distribuida en archivos para facilitar mantenimiento y pruebas.
Características principales
- Registro de hasta 10 productos (nombre y precio).
- Cálculo del precio total del inventario.
- Identificación del producto más caro y del más barato.
- Cálculo del precio promedio de los productos.
- Búsqueda de productos por nombre (case-insensitive).
- Visualización completa del listado de productos.
- Proyecto modular dividido en main.c, funciones.c y funciones.h.
